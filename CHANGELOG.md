# Changelog
All notable changes to this project will be documented here.

## [1.3.0] – 2026-06-27
### Added
- **Quick-create deep links** — hover over Word, Excel, PowerPoint, OneNote, or Teams to reveal a `+` button that opens a blank new document or meeting directly, skipping the app home screen
- **Keyboard shortcuts** — press `O` / `T` / `W` / `E` / `P` / `D` / `N` / `B` / `A` / `F` to launch apps when no input is focused; press `?` for the full cheat sheet overlay
- **Admin portals section** — collapsible section below the main grid with direct links to M365 Admin, Entra ID, Exchange Admin, Teams Admin, Intune, Purview, Security, Azure Portal, and Power Platform Admin Center; collapsed by default
- **Power Platform section** — collapsible section with quick-launch links to all makers (Power Apps, Power Automate, Power Pages, Copilot Studio, Power BI, PPAC) plus an environment switcher: save named environments by GUID and get direct deep links to Solutions, Apps, Dataverse tables, Flows, and environment settings
- **Narrow viewport layout** — improved rendering for Vivaldi web panels, sidebar browsers, and narrow screens; header scales down, tile grids reflow tighter, quick-create buttons always visible without hover

## [1.2.0] – 2025-06-14
- Add Edit mode to allow adding custom cards, editing/deleting existing cards 
- Add “Export/Import” JSON buttons in Edit mode, to allow moving config beyon localStorage

## [1.1.0] – 2025-06-11

## [1.0.0] – 2025-06-10

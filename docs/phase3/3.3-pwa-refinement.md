# 3.3 PWA refinement

## Goal
Make the installed PWA experience polished enough that people genuinely use it as their M365 homepage — on desktop via "Install app" and on mobile via "Add to home screen".

## Current state
Basic PWA manifest exists. Offline experience is undefined (probably shows a browser error page).

## Changes needed

### manifest.json
```json
{
  "name": "offi.ceo — Office App Launcher",
  "short_name": "offi.ceo",
  "display": "standalone",
  "start_url": "/",
  "background_color": "#ffffff",
  "theme_color": "#0078d4",
  "icons": [
    { "src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icons/icon-512.png", "sizes": "512x512", "type": "image/png" },
    { "src": "/icons/icon-512-maskable.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]

```

### Service worker (offline fallback)
- Cache the app shell on install (index.html, CSS, JS bundle)
- Cache-first for app shell assets; network-first for Graph API calls
- Offline fallback: show the tile grid from localStorage (works without auth), widgets show "offline" state
- Use Vite PWA plugin (`vite-plugin-pwa`) — handles service worker generation automatically

### Install prompt
- Detect `beforeinstallprompt` event; store it
- Show a subtle "Install as app" button in the controls bar (dismissible, stored in localStorage)
- Don't nag — show once, if dismissed don't show again for 30 days

### Icons
Need proper icons at 192×192 and 512×512. Current emoji-based approach won't produce good home screen icons. Design a simple icon using the offi.ceo branding (the domain name / "O" lettermark against M365 blue).

## Push notifications (optional, low priority)
- Web Push API for meeting reminders: "Your meeting starts in 5 minutes"
- Requires notification permission + a push server (breaks the no-backend principle)
- Defer unless there's clear user demand — the calendar widget already handles the visual prompt

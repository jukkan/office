# 3.1 Dashboard layout control

## Goal
Let users control the layout of their dashboard — which sections appear, in what order, and how dense the tiles are. All preferences in localStorage, no account needed.

## Controls
- **Section order**: drag-and-drop reordering of the main tile grid, widget area, admin section, PP section — use `@dnd-kit/core` (already a viable addition; check bundle size)
- **Section collapse**: each section independently collapsible; state persisted
- **Tile density**: "Comfortable" (current, larger tiles) vs "Compact" (smaller tiles, more per row) — CSS class toggle on the grid container
- **Widget visibility**: toggles per widget (recent files, meeting, email count, sites) — show/hide without removing their data hooks

## localStorage keys
```
layout_section_order       // string[] of section IDs in display order
layout_tile_density        // "comfortable" | "compact"
widget_recent_files        // boolean
widget_next_meeting        // boolean
widget_email_count         // boolean
widget_followed_sites      // boolean
```

## Notes
- DnD library: `@dnd-kit/sortable` is the right choice over `react-beautiful-dnd` (which is unmaintained)
- Section IDs: `"main"`, `"admin"`, `"powerplatform"`, `"widgets"`
- This feature is only worth building after Phase 2 widgets exist — don't build the reordering UI for a page with one section

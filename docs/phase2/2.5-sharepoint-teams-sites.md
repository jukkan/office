# 2.5 Followed SharePoint sites and joined Teams

## Goal
Surface the SharePoint sites and Teams the user has explicitly followed/joined. Replaces the "Sites" and "Teams" views that used to live in the old office.com sidebar.

## Graph API

### Followed sites
```
GET /me/followedSites
  ?$select=displayName,webUrl,description
```

### Joined Teams
```
GET /me/joinedTeams
  ?$select=displayName,webUrl,description
```

## UI
- Two-column list widget: "My sites" | "My teams" as tabs or split sections
- Each entry: icon, name, optional description snippet, direct link
- User can pin items to the main tile grid from here (stored in localStorage)
- Limited to top 10 per list; "View all in SharePoint" / "View all in Teams" links at bottom

## Pinning to main grid
- Pin icon on each entry — clicking adds a custom tile to the main grid with name + URL
- Same `AppTile` structure, just pre-filled from the site/team data
- This is the connective tissue between the Graph data and the user's personalised launcher

## Hook: `src/graph/useFollowedSites.ts`
Stale time: 30 minutes (this data changes infrequently).

## Scope required
`Sites.Read.All` — note this scope sounds broad but is standard for reading site metadata the user follows

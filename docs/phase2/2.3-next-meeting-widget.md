# 2.3 Next meeting widget

## Goal
Show the next 1–3 calendar events. For Teams meetings, surface a direct Join button. Highlight imminent meetings.

## Graph API
```
GET /me/calendarView
  ?startDateTime={now_ISO}
  &endDateTime={now_plus_24h_ISO}
  &$top=3
  &$select=subject,start,end,organizer,onlineMeeting,isOnlineMeeting,bodyPreview
  &$orderby=start/dateTime
```

`onlineMeeting.joinUrl` is the Teams join link. Present only when `isOnlineMeeting === true`.

## UI states
| State | Display |
|-------|---------|
| No meetings today | "No meetings today" with a small calendar icon |
| Meeting in >15 min | Title, time, organiser name |
| Meeting in ≤15 min | Highlighted card (accent background), "Join now" button prominent |
| Meeting in progress | "In progress" badge, "Join now" button |

- Times shown in user's local timezone (JS `Intl.DateTimeFormat`)
- Meeting title truncated at ~40 chars

## Hook: `src/graph/useNextMeeting.ts`
Refetches every 5 minutes (`refetchInterval: 5 * 60 * 1000`). 24-hour lookahead window.

## Scope required
`Calendars.Read`

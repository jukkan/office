# 2.2 Recent files widget

## Goal
Show the last 8–10 files the signed-in user worked on across OneDrive and SharePoint. The single feature most likely to make people return daily.

## Graph API
```
GET /me/drive/recent
  ?$top=10
  &$select=name,lastModifiedDateTime,webUrl,file,parentReference
```

Response includes `file.mimeType` and `@microsoft.graph.downloadUrl` — use mime type to filter and pick the right icon.

## File types to show
| MIME type | Icon | Label |
|-----------|------|-------|
| `application/vnd.openxmlformats-officedocument.wordprocessingml.document` | 📝 | Word |
| `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` | 🧮 | Excel |
| `application/vnd.openxmlformats-officedocument.presentationml.presentation` | 📈 | PowerPoint |
| `application/onenote` | 📔 | OneNote |
| `application/pdf` | 📄 | PDF |

Everything else is filtered out of the list. If fewer than 3 Office files in results, fetch more (`$top=25`) and filter.

## UI
- Widget card with header "Recent files" + refresh icon
- Each file row: app icon, truncated filename, relative time ("2 hours ago"), direct `webUrl` link
- Clicking opens the file in the browser (online editor)
- Loading state: skeleton rows
- Error state: "Couldn't load files" with retry button

## Hook: `src/graph/useRecentFiles.ts`
Uses TanStack Query with a 5-minute stale time. Returns `{ files, isLoading, error, refetch }`.

## Scope required
`Files.Read` — request this incrementally when the widget first renders (MSAL incremental consent)

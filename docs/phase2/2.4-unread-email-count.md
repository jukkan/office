# 2.4 Unread email count

## Goal
Show unread inbox count as a number badge. No email content, no previews — intentionally minimal. Clicking opens Outlook Web.

## Graph API
```
GET /me/mailFolders/inbox
  ?$select=unreadItemCount
```

Single lightweight call, returns one number.

## UI
- Small widget or badge near the Outlook tile (or a dedicated mini-widget in the header)
- Shows count number; if 0, shows nothing or a subtle "✓" — don't display a zero badge
- If >99, show "99+"
- Clicking anywhere on it opens `https://outlook.office.com/mail/inbox`
- Refresh every 10 minutes passively; refresh button on hover

## Design decision
This should be a badge on the Outlook tile rather than a standalone widget card. Keeps the layout clean and the information contextual — you see the unread count on the thing you'd click to deal with it.

## Hook: `src/graph/useEmailCount.ts`
Returns `{ unreadCount: number | null, isLoading, error }`.

## Scope required
`Mail.Read`
